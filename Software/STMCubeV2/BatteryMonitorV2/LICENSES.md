# Licenses — BatteryMonitorV2

## Project license

The project's own source code (everything under `Core/Src/` that
isn't autogenerated, plus `scripts/`, `test/`, `tools/`, and any
hand-written headers under `Core/Inc/`) is licensed under
**GNU General Public License v3.0 or later** (`GPL-3.0-or-later`).
See [LICENSE](LICENSE) for the full text.

This may be relaxed to a more permissive license (MIT / BSD)
later — provisional choice while the project is in bring-up. The
relaxation is only blocked if a third-party component we depend on
has a copyleft clause that would force GPL on downstream users
(none of the components below do — they're all permissive).

### Why GPL v3, not GPL v2

CMSIS Core and CMSIS Device (both Apache-2.0) are
**incompatible with GPL v2** but **compatible with GPL v3**.
Apache 2.0's explicit patent grant and termination clauses can't
be honoured under GPL v2's terms, but GPL v3 was designed to
accept them. Picking v3 keeps the firmware as a whole legally
linkable.

## Per-component details

### TinyUSB — USB device stack

- **Where:** [Middlewares/tinyusb/](Middlewares/tinyusb/)
- **License:** MIT
- **Version:** 0.20.0 (see [Middlewares/tinyusb/VERSION.txt](Middlewares/tinyusb/VERSION.txt))
- **Used for:** USB-FS CDC ACM telemetry on PA11/PA12 (also serves as the
  DFU programming port via the chip's built-in bootloader, which is
  separate from TinyUSB).

### u8g2 — Monochrome OLED graphics library

- **Where:** [Middlewares/u8g2/](Middlewares/u8g2/)
- **License:** BSD 2-Clause "Simplified" ("new BSD")
- **Version:** 2.36.19 (see [Middlewares/u8g2/VERSION.txt](Middlewares/u8g2/VERSION.txt))
- **Used for:** SSD1306-family 128×32 OLED driver on I2C2 — page-buffer
  mode `_1` to keep RAM minimal.
- **Trim notes:** only `csrc/` (engine + display dispatchers) and
  `sys/sdl/common/` (SDL backend for a future desktop sim) are
  vendored. The stock-font mega-file (`csrc/u8g2_fonts.c`, 39 MB) is
  intentionally excluded — we generate custom fonts via upstream
  `bdfconv` instead.

### u8g2 BDF fonts (5x7, 9x15B, 9x18B)

- **Where:** [Core/Src/fonts/*.c](Core/Src/fonts/) (autogenerated from upstream BDFs)
- **License:** Public domain ("Public domain font. Share and enjoy." — embedded
  in the source BDF headers and carried into the generated u8g2 font arrays)
- **Source:** [u8g2's tools/font/bdf/](https://github.com/olikraus/u8g2/tree/master/tools/font/bdf)
  — these are the venerable X Window System fixed-width / Misc-Fixed
  fonts (5x7, 9x15B, 9x18B), all explicitly public domain in their
  BDF headers.
- **Generation:** [scripts/build-fonts.sh](scripts/build-fonts.sh) builds
  upstream bdfconv on demand, packs printable-ASCII subsets into u8g2's
  binary format, and prepends a `#include "u8g2.h"`. Re-run after a
  u8g2 version bump.

### FreeRTOS Kernel 11.2

- **Where:** [Middlewares/Third_Party/FreeRTOS/](Middlewares/Third_Party/FreeRTOS/)
- **License:** MIT
- **Distribution:** Vendored by the X-CUBE-FREERTOS pack via STM32CubeMX
  (not by the STM32CubeC0 base package — `Hard rule 5` in
  [CLAUDE.md](CLAUDE.md) notes the project standardises on
  X-CUBE-FREERTOS, not the legacy middleware).
- **Used for:** task scheduling, mutexes, semaphores, CMSIS-RTOS V2 API
  surface used throughout `Core/Src/*_task.c`.

### STM32 HAL — STM32C0xx_HAL_Driver

- **Where:** [Drivers/STM32C0xx_HAL_Driver/](Drivers/STM32C0xx_HAL_Driver/)
- **License:** BSD 3-Clause (per the LICENSE.txt: "the terms of the
  BSD-3-Clause license shall apply" when received outside ST's
  package distribution)
- **Vendor:** STMicroelectronics
- **Distribution:** Installed by STM32CubeMX as part of the STM32CubeC0
  firmware package (V1.4.0 per the `.ioc`).
- **Used for:** Every HAL_* call in the firmware — I2C, USB, GPIO, TIM,
  RCC, DMA. Outside the `USER CODE BEGIN/END` blocks, all HAL code is
  CubeMX-generated and not hand-edited.

### CMSIS Core (ARM)

- **Where:** [Drivers/CMSIS/](Drivers/CMSIS/) (top-level files; per-device parts under `Device/ST/STM32C0xx/`)
- **License:** Apache 2.0
- **Vendor:** ARM Limited
- **Used for:** Cortex-M0+ register / NVIC / SysTick definitions
  consumed transitively via the HAL.

### CMSIS Device — STM32C0xx

- **Where:** [Drivers/CMSIS/Device/ST/STM32C0xx/](Drivers/CMSIS/Device/ST/STM32C0xx/)
- **License:** Apache 2.0 (per the LICENSE.txt: "the terms of the
  Apache-2.0 license shall apply" when received outside ST's package)
- **Vendor:** STMicroelectronics (extending ARM's CMSIS Core)
- **Used for:** STM32C071-specific register maps, peripheral structs,
  startup code (`startup_stm32c071xx.s`).

### picolibc — C standard library (runtime)

- **Where:** Linked from the ARM LLVM Embedded Toolchain — not vendored
  in this repo. The toolchain is installed by
  [scripts/setup-wsl.sh](scripts/setup-wsl.sh) (CI) or the bundled
  st-arm-clang under `$CUBE_BUNDLE_PATH` (developer).
- **License:** Mostly BSD-3-Clause and BSD-2-Clause; some files under
  other permissive licenses. See picolibc's
  [COPYING.picolibc](https://github.com/picolibc/picolibc/blob/main/COPYING.picolibc)
  for the per-file breakdown.
- **Used for:** `printf` / `snprintf` (forced to integer-only vfprintf
  via `-Wl,--defsym=vfprintf=__i_vfprintf` in
  [cmake/starm-clang.cmake](cmake/starm-clang.cmake)), `memcpy`, etc.
- **Distribution:** Toolchain artifact; not redistributed with this
  repo's source. Downstream users who ship a binary built against
  picolibc need to comply with the picolibc license themselves.

## Maintenance

- When vendoring a new dependency under `Middlewares/`, drop its
  upstream `LICENSE` (and `VERSION.txt` documenting the upstream URL
  + bump procedure) alongside the source, then add a row to the
  Summary table above and a per-component section below it.
- When updating CubeMX / X-CUBE-FREERTOS / the STM32CubeC0 package,
  the LICENSE files under `Drivers/` and `Middlewares/Third_Party/`
  may change — re-check them and update this file if the SPDX
  identifier shifts.
- This file inventories software only. CAD outputs, datasheets, and
  design documents under [../../../CAD/](../../../CAD/),
  [../../../Datasheet/](../../../Datasheet/),
  [../../../Design/](../../../Design/), and
  [../../../Docs/](../../../Docs/) have their own licensing concerns
  (KiCad project file licensing, vendor datasheet redistribution
  terms, etc.) that are out of scope here.
